# 🚗 ParkEase — Smart Parking Management & Slot Booking

ParkEase is a web-based **Smart Parking Management and Slot Booking System** designed to make parking slot discovery, booking, payment demonstration, and booking management simple and user-friendly.

The project provides separate user and admin functionality with a responsive interface and browser-based data storage.

---

## 📌 Project Overview

ParkEase allows users to:

* View available parking zones
* Check parking slot availability
* Select and book a parking slot
* Enter booking details
* Complete the demo payment flow
* Generate a parking ticket
* View booking history
* View QR code for booking/ticket details
* Manage bookings through the admin panel

The project is developed as a **frontend web application** using HTML, CSS and JavaScript.
