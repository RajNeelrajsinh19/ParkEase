ParkEase Structured Project

Files
- index.html: main app shell
- css/style.css: all styles
- js/script.js: all JavaScript behavior
- assets/images/: placeholder for future images
- assets/icons/: placeholder for future icons

Run locally
1. Open this folder in VS Code.
2. Start a local server, for example: py -m http.server 8000
3. Open http://127.0.0.1:8000/index.html

Notes
- The app is a frontend demo.
- QRCodeJS is loaded from CDN in index.html.
- Bookings and sessions persist in localStorage.
